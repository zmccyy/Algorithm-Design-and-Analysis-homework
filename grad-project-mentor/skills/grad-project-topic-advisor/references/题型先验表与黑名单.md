# "烂大街"黑名单

智能垃圾桶、循迹/避障小车（裸版）、温湿度+OLED 显示、ESP8266 远程开关灯、红外智能风扇、指纹门锁、电子万年历（模块拼装版）。

# 解药公式：经典题 + 一个新东西 = 稳又新

| 原题（黑名单） | 增量改造后 | 增量点 |
|---|---|---|
| 循迹避障小车 | 小车 + 循迹 PID + 编码器测速 + IAP 远程固件升级 | 从套件级跳到有通信协议+Bootloader 的工程题 |
| 电子万年历 | 万年历 + 农历算法自己写（不用现成库）+ TF 卡数据记录 | 老师问"农历怎么算的"时是真东西 |
| 环境监测 | 环境监测 + 本地智能预警 + FreeRTOS 多任务 | 从"读寄存器→显示"升级到有算法和调度 |
| 任意题 | + ESP32-S3 离线语音/大模型接入 | 2027 年答辩效果最炸的增量，成本几十块 |

增量方向优先级：算法闭环 > 通信升级（IAP/OTA）> 数据出口（上位机/云/TF卡）> AI 交互。
