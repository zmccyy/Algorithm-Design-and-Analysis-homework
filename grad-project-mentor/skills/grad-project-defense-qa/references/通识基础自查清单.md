# 通识基础自查清单（每条 30 秒内答出核心）

> 题目用到的每个技术点，对应基础概念必须脱口而出——评委靠这个判断"是不是自己做的"。

- [ ] **用串口**：波特率/起始位停止位/校验位？波特率不匹配什么现象？
- [ ] **用 I2C**：时序（起始/停止/ACK）？为什么上拉电阻、阻值怎么定？地址冲突怎么办？
- [ ] **用 ADC**：分辨率/参考电压/采样率关系？量化误差怎么算？
- [ ] **用中断**：中断里为什么不能用 delay？volatile 何时必须加？优先级怎么配？
- [ ] **用 PWM**：频率怎么选（电机嗡嗡声/LED 闪烁）？占空比与输出关系？
- [ ] **用 FreeRTOS**：任务间通信（队列/信号量）？优先级反转是什么、怎么防？
- [ ] **用电机**：为什么驱动板要续流二极管？H 桥原理一句话？
- [ ] **用电池供电**：功耗估算怎么做的？低功耗模式怎么进的？

答不出的标记"答辩前必须补"——这类题最容易在追问链第一层就崩。
