# 查重风险自查清单

## 四类高危段落与对策

| 高危段落 | 为什么重复 | 对策 |
|----------|------------|------|
| 芯片介绍（"STM32F103 是一款…"） | 千篇一律抄数据手册 | 只写与本设计相关的参数和选型理由 |
| 方案描述 | 套模板句式 | 用自己的框图+实测数据说话 |
| 研究现状 | 综述句式雷同 | 每条现状落到具体文献的具体结论 |
| 原理阐述（传感器原理等） | 教科书原文 | 用"在本设计中，它被用来…"的语境重写 |

## 压雷同三招

1. **每段绑定自己的实测数据/截图**——"实测输出电压 3.28V，与理论 3.3V 偏差 0.6%"这句不可能重复
2. **原理图/流程图自己重画**——别截数据手册原图（防查重又清晰）
3. **逐句自问**——把可疑段落逐句问自己"这句话是我的话吗"
