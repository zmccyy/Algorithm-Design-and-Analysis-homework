# 现场演示防翻车检查清单

## 演示前 1 小时过一遍

- [ ] 电池满电（或电源适配器就位）
- [ ] 烧录最新固件（版本确认）
- [ ] 外设接线牢固（轻晃测试）
- [ ] 演示环境就绪（网络/上位机/手机 APP）
- [ ] 备用数据线/备用手机
- [ ] 演示视频已拷到答辩电脑本地（不依赖网络播放）

## 演示台词结构

1. 演示前一句话："现在大家将看到 XX"
2. 演示中手指实物："这一步是 XX 传感器在工作"
3. 演示后收束："以上完成了 XX 指标验证，数据在论文第 X 章"

## 翻车话术

"设备刚才连续运行了 X 小时，可能是现场 XX 干扰，我这里有提前录制的完整演示视频。"

——诚实 + 有预案 = 加分项。慌乱重启超过 2 次就切视频，别硬撑。
